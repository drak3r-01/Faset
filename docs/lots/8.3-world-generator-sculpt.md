# Lot 8.3 - World generator and editor sculpting tools (phase 8, world)

Not in the reference plan. Phase 8 turns the arena maps into believable worlds (see `README.md`).

- **Model/effort:** Sonnet, high | **Depends on:** 8.1 | **Branch:** `lot/8.3-world-generator-sculpt` (one PR)
- **Owns:** `mapfmt` (generator, deterministic), `editor` (tools), `tools/map-scripts`. Additive changes elsewhere.

## Goal

Start a map from believable natural relief instead of a blank plane, then refine it by hand in the editor.

## Spec

1. **Deterministic relief generator** from a seed and parameters: fractal noise, ridges, hydraulic and thermal erosion, valleys, plateaus; presets per theme (coast, forest valley, canyon, quarry, island).
2. **Water and rivers:** carve river beds and lakes, shore banks, sea level; water surface uses the lot 2.8 water.
3. **Editor tools:** raise/lower/smooth/flatten (existing), stamp (hill, cliff, crater), erode, carve river, path/road that flattens and paints, undo/redo, all saved in the map file.
4. **Painting and vegetation brush:** paint material layers and scatter vegetation with density, species mix and random size, deterministic from a seed, live preview in the editor.

## Acceptance

`cargo xtask ci` green; generator is byte-reproducible for a seed (test); sculpt and brush round-trip tests; editor lavapipe screenshots of each tool.
