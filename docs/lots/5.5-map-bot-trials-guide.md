# Lot 5.5 — Map trials by bots, statistics, design guide
- Model/effort: Sonnet, medium | Depends on: 4.10, 3.3 | Milestone: none

## Goal
`map-tool` plays 16 bots on a map without rendering and produces a trial report; the map design guide gives authors the dimensions to respect.

## Crates
- Owned: `tools/map-tool` (trial command), `docs/map-design-guide.md` (new file, English).
- Read-only: `mapfmt`, `sim`, `bots`, `minigame-api`, `mode-fps`, `server`, `render` (not used for trials), `core`.
- Forbidden: changing public interfaces of read-only crates.

## Spec
Trial run:
- 16 bots play 5 minutes of match time, accelerated, with no rendering, on the map given as argument.
- Fixed seed: same map, same mode and same seed give an identical report (determinism).
- Report (JSON) contains:
  - elimination zones (where deaths happen, as cells or boxes with counts);
  - death rate at spawn (deaths within a short radius of spawn points);
  - mean engagement distance;
  - zones never visited;
  - team balance (kills and time per team).

Design guide `docs/map-design-guide.md` must contain this table of dimensions:
| Dimension | Value |
|---|---|
| Corridor width | at least 3 m |
| Door | 2 m × 2.5 m |
| Low cover, high cover | 1.0 m and 2.0 m |
| Step climbable without jump | 0.45 m |
| Obstacle climbable by jumping | 1.0 m |
| Gap crossable while running | 4 m |
| Recommended maximum line of sight | 60 m |

The guide also states the authoring loop used by sessions: sheet (theme, mode, players, layout archetype), ASCII grid schema (zones, passages, heights), RON writing, `map-tool validate`, top view and three perspective renders, correction for at most 3 rounds, bot trial, then human validation before the catalogue.

## Public interfaces to create or respect
- `map-tool trial <map> --seed <n> --out <report.json>`.
- Report JSON schema: fixed field names listed above, with a `schema_version` field.

## Acceptance criteria
- `dev.ps1 test` passes:
  - the trial on the sample map (from `assets/maps/`) produces a report with all five metric fields;
  - two runs with the same seed produce byte-identical reports;
  - the guide contains every value in the table above (test greps the file).
- Run `dev.ps1 maps validate` before trials; it must pass.
- Report produced for the sample map and attached to the PR description (summary numbers).
- `dev.ps1 ci` passes.

## Out of scope
- AI map generation loop itself (outside the lot); catalogue maps (5.6); changing bot behaviour (4.10).
