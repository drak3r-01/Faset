# Lot 2.16 — `egui` integration, theme, debug overlay
- Model/effort: Sonnet, medium | Depends on: 2.2 | Milestone: none

## Goal
Draw `egui` interfaces at display resolution after upscaling, with one theme and a debug overlay (puffin profiling, frame times, network graph, simulation stats).

## Crates
- Owns: `ui` (create it; depends on `core` and `render`).
- Read-only: `render` (pass 9 hook, lot 2.2), `core`.
- Forbidden: changing the public interface of `render`. If pass 9 has no hook, stop and report.
- Errors: `thiserror`. Logs: `tracing`.

## Spec
- `egui` is drawn at display resolution (pass 9), after upscaling (lot 2.10) and after the post-processing pass 7. It is not affected by the render scale.
- Theme: one struct of colour tokens in `ui`, used by all screens. Accessibility filters come later (phase 6).
- Debug overlay (toggle key set in configuration, not hard-coded): `puffin` profiling; frame times; network graph; simulation statistics.
- Budgets this lot must respect: CPU time per frame under 4 ms in total; total draw calls under 500 (UI included).
- Interface text is a translation key looked up in a table. The English table comes first; French is added later.
- The application state stack (`Boot`, `MainMenu`, `ServerBrowser`, `HostSetup`, `Loadout`, `Settings`, `Connecting`, `Loading`, `InGame`, `Editor`) is implemented in phase 6. Here, expose only a draw entry point that accepts one screen.

## Public interfaces to create or respect
- `ui::Theme` (colour tokens), `ui::Ui::begin_frame`, `ui::Ui::draw(screen)`, `ui::Overlay::toggle()`, `ui::text(key) -> &str`.
- Consumes `render` pass 9 hook.

## Acceptance criteria
- `cargo xtask render-test`: a headless UI frame on lavapipe matches its reference within tolerance; zero validation-layer messages.
- Test: the UI pass index is greater than the upscale pass index in the frame order.
- Test: the overlay is absent when off and shows frame time and network sections when on (reference image).
- Test: a missing translation key returns the key itself and logs a warning.
- `cargo xtask build --target x86_64-pc-windows-msvc` and `x86_64-unknown-linux-gnu` succeed.
- `cargo xtask ci` passes in Docker.

## Out of scope
- Main menu and screens (phase 6), settings screen generated from metadata (lot 6.4).
- HUD of the FPS mode (lot 4.8).
- French translation table.
