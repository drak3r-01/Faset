# Lot 2.7 — Weather: particles, shelter, humidity, storm, transitions
- Model/effort: Sonnet, élevé | Depends on: 2.4, 2.6 | Milestone: none

## Goal
Render visual weather (rain, snow, sand, fog, wind, humidity, storm) driven by a weather vector with timed transitions, using stateless GPU particles; rain, snow and sand references must match.

## Crates
- Owned: `render` (weather pass, particle shader, shelter map); WGSL in `shaders`.
- Read-only: `core`. Forbidden: all other crates. The network delivery of weather schedules is a later lot (1.x); here the schedule is a local input struct.

## Spec (condensed)
- State is a vector: rain, snow, sand, fog, wind, humidity, storm (each in [0,1]; wind as a vector).
- Transitions interpolate the whole vector over 10 to 30 s (per transition, a value in that range).
- Weather is visual and audible only; no effect on physics in the initial version.
- Stateless particles: position computed in the vertex shader from particle index, time and a box that follows the camera. Zero CPU cost per particle (plan form; hash(i) per-particle hash, v velocity, t time, B box size, O_cam camera-following offset):
```
p_i = \mathrm{fract}\!\left(\mathrm{hash}(i) + \frac{v\,t}{B}\right) B + O_{cam}
```
- Rain: quads stretched along the velocity. Snow: lateral oscillation (sinusoidal sway added to a fall). Sand: horizontal streaks and stronger fog.
- Shelter: a height map seen from above is rendered once at map load. A particle below a roof (height map above particle height) is masked out.
- Humidity: darkens surfaces, adds reflections and procedural puddle ripples (ripple pattern from lot 2.3).
- Storm: lightning flashes briefly raise the light intensity. Thunder delay = distance / 343 m/s; emit `ThunderEvent { delay_s }` for the audio lot.
- Desert profile: heat haze shimmer applied in post (2.9 screen distortion path).

## Public interfaces to create or respect
- `pub struct WeatherState { pub rain: f32, pub snow: f32, pub sand: f32, pub fog: f32, pub wind: Vec3, pub humidity: f32, pub storm: f32 }` (serde).
- `pub struct WeatherSchedule` with `fn sample(&self, t: f32) -> WeatherState` (interpolates keyframes; transition 10-30 s).
- `pub struct ThunderEvent { pub delay_s: f32 }` (emitted by `render` for audio).
- `RenderWorld` gains `weather: WeatherState`; `render::ShelterMap::from_heights(...)` built at map load.

## Acceptance criteria
- `cargo xtask render-test`: references `weather_rain.png`, `weather_snow.png`, `weather_sand.png` match within tolerance 1 per channel.
- Unit: `WeatherSchedule::sample` at a transition's start and end equals the keyframes; midpoint is the average.
- Unit: transition durations outside 10-30 s are rejected.
- Unit: a particle under a synthetic roof (height map) is masked; one outside is not.
- Unit: thunder delay for 343 m equals 1.0 s; for 0 m equals 0.
- Zero validation-layer messages.

## Out of scope
Physics effects of weather, gameplay slowdown, networked weather events, sound, particle collisions with geometry, lightning sound.
