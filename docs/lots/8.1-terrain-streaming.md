# Lot 8.1 - Large terrain: format v5, chunk streaming, clipmap LOD (phase 8, world)

Not in the reference plan. Phase 8 turns the arena maps into believable worlds (see `README.md`).

- **Model/effort:** Opus, high | **Depends on:** 6.10, 6.12 | **Branch:** `lot/8.1-terrain-streaming` (one PR)
- **Owns:** `mapfmt` (format v5), `render` (terrain pipeline), `client` (streaming). Public interface changes of these crates are allowed for this lot only; document them in the report.

## Goal

A map can sit on a 1 to 2 km terrain with smooth ground, while only the 150 to 300 m playable zone is simulated.

## Spec

1. **Format v5** (backward compatible, migration by version bump): a `World` block with the world extent, the playable rectangle, a sculpted high-resolution height grid for the playable zone and a coarse far height field. Decision: far terrain either stored coarse or regenerated from a seed and parameters (smaller map transfer; it is client-only, the simulation never reads it). Record the chosen map transfer size.
2. **Chunked terrain mesh with LOD** (geomorphing or skirts so there are no cracks or popping), frustum culling, chunks streamed in a budgeted way per frame, no hitch when turning.
3. **Smooth ground look:** per-vertex smooth normals, 4 to 6 blended material layers (grass, dirt, rock, sand, snow/mud per theme) from slope, height and painted weights, a detail normal/noise at close range, triplanar mapping on cliffs so there is no stretching. Own palette, no external textures.
4. **Simulation:** playable-zone terrain collision stays the lot 6.10 code path (same code on server and client prediction); terrain outside the playable rectangle is visual only. Existing replay traces unchanged.
5. Migrate Pine Hollow to a 1 km world as proof (full rebuilds are lots 8.9 to 8.11).

## Acceptance

`cargo xtask ci` green; determinism and prediction tests on slopes still pass; lavapipe screenshots of the proof map from spawn and from the border; chunk streaming bounded in memory and per-frame time (test); v4 maps load unchanged.
