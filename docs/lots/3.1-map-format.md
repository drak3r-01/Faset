# Lot 3.1 — `mapfmt`: map format
- Model/effort: Opus, medium | Depends on: 0.2 | Milestone: none

## Goal
Implement the versioned RON map format in crate `mapfmt` (schema, symmetry, prefabs, BLAKE3 fingerprint, migration) so that the example map is read and rewritten byte-identically.

## Crates
- Owns: `mapfmt`, and the new file `assets/maps/example.ron`.
- Read-only: `core` (typed ids, glam re-export, config helpers).
- Forbidden: every other crate. `mapfmt` depends only on `core`.

## Spec (condensed from plan sections 13 and 1)
- A map is one RON file, versioned (`format_version: u32`), made of simple volumes on a 0.5 m grid.
- Volume (brush) coordinates are integers in half-metres (1 unit = 0.5 m); props, spawns and pickups use floats, as in the example below.
- Units: metre, second, radian; right-handed, Y up, -Z forward. Data in RON.
- Format example (plan section 13, verbatim; `example.ron` follows this shape):
```
Map(
    format_version: 1,
    meta: (name: "Cargo", modes: ["fps"], players: (2, 12)),
    theme: (ambience: "sunset", palette: "industrial"),
    symmetry: Rotate180,
    brushes: [
        Box(min: (-40, -1, -30), max: (40, 0, 30), material: "concrete"),
        Box(min: (4, 0, -6), max: (10, 3, -3), material: "container_red"),
        Wedge(min: (10, 0, -6), max: (14, 3, -3), rise: PosX, material: "metal"),
    ],
    props: [(recipe: "crate_wood", at: (2.0, 0.0, 5.0), yaw: 15.0)],
    spawns: [(at: (-36.0, 0.0, -26.0), yaw: 45.0, team: A)],
    pickups: [(kind: Health, at: (0.0, 0.5, 0.0), respawn_s: 30)],
)
```
- Top-level blocks, exact names: `meta` (name, author, description, compatible mode labels, recommended player count); `theme` (mood profile, sky, weather calendar, colour palette); `physics` (optional local overrides of gravity and speed); `symmetry` (`None` | `MirrorX` | `MirrorZ` | `Rotate180`); `prefabs` (reusable groups of brushes and props); `brushes` (`Box`, `Wedge`, `Cylinder`, `Prism`, `Stairs`); `props` (recipe id + position, rotation, scale); `spawns` (position, orientation, team); `pickups` (location, type, respawn delay in s); `zones` (`KillVolume`, `Water`, `JumpPad`, `Teleporter`, `LowGravity`, `Objective`); `lights` (point lights).
- Symmetry is declared, not written: the author describes one half and the map expands it. Spawns and pickups are mirrored too.
- Prefabs: a group is described once and placed several times; expansion is done at load.
- Size limit: plan says "256 ko"; decision: 256 KiB, `MAX_MAP_BYTES = 262_144`.
- Identity: map id = BLAKE3 of the canonical form. Canonical form (decision, not in plan): the parsed model re-serialised with fixed field order, LF newlines, no comments, after migration. Network never uses file names as paths.
- Migration: `format_version` selects a chain of functions `vN -> vN+1`. A version newer than `FORMAT_VERSION` is an error.
- Mirror geometry (decision): `MirrorX` mirrors across the plane x = 0 of the map origin, `MirrorZ` across z = 0, `Rotate180` about the vertical axis through the origin. Mirrored `Box` swaps min/max on the mirrored axis. Mirrored spawns and pickups keep position and orientation mirrored; a mirrored spawn gets the other team.

## Public interfaces to create
- `pub const FORMAT_VERSION: u32`, `pub const MAX_MAP_BYTES: usize = 262_144`.
- `pub struct MapFile` (serde, all blocks above), enums `Symmetry`, `Brush`, `Zone`, `ZoneKind`.
- `pub fn parse(bytes: &[u8]) -> Result<MapFile, MapError>` (runs migrations).
- `pub fn to_ron(map: &MapFile) -> String` (canonical, deterministic).
- `pub fn fingerprint(map: &MapFile) -> [u8; 32]` (BLAKE3 of the canonical bytes).
- `pub fn expand_symmetry(map: &MapFile) -> MapFile`, `pub fn expand_prefabs(map: &MapFile) -> MapFile`.
- `MapError` via `thiserror`; variants at least: `Parse`, `UnknownVersion`, `TooLarge`, `Invalid`.

## Acceptance criteria
- `cargo xtask test`: round trip `parse(example) -> to_ron` gives bytes identical to `assets/maps/example.ron`; `parse` of that output gives an equal `MapFile`.
- `fingerprint` is the same across two runs and changes when one coordinate changes.
- A file with a future `format_version`, an unknown field or more than 256 KiB returns the matching `MapError`.
- `cargo xtask check` passes (fmt, clippy `-D warnings`).
- `example.ron` contains at least one brush of each kind and one symmetry declaration, so that the expansion is tested.

## Decisions and deviations (recorded by the lot 3.1 session)
- Crate is `crates/mapfmt`, package `faset-mapfmt`; external deps `serde`, `ron 0.12`, `blake3 1.8`, `thiserror`.
- Canonical form: serde field order of the structs, RON pretty printing with 4-space indent, LF, depth limit 2 (top-level fields and list items one per line, deeper values inline), only the top-level struct named (`Map(`), trailing newline. Empty lists, empty optional strings, absent optional values and default values (`scale: 1.0`, `turns: 0`) are omitted. `symmetry` is always written.
- Optional values (`physics`, `gravity`, `speed_scale`) are written bare, without `Some(...)`.
- Angles in the file (`yaw`) are degrees about +Y, counter-clockwise seen from above, 0 facing -Z. Deviation from the radian rule, to match the plan's verbatim example (`yaw: 15.0`, `yaw: 45.0`); consumers convert with `to_radians`.
- Props carry yaw and uniform scale only (no pitch/roll).
- Brush shapes: `Box`, `Wedge` (`rise` = high side), `Cylinder` (inscribed in min/max, `axis`, `sides >= 3`), `Prism` (vertical extrusion of an `(x, z)` polygon, `y_min`/`y_max`, counter-clockwise), `Stairs` (`rise`, `steps`).
- `Team` is `A | B | Any`; mirroring swaps A and B, `Any` stays.
- `PickupKind` is `Health | Armor | Ammo | Weapon(id)`; `respawn_s` is an integer.
- `Zone` is an enum of shapes (only `Box { min, max, kind }` so far, half-metre grid); `ZoneKind` variants: `KillVolume`, `Water`, `JumpPad { velocity }`, `Teleporter { target, yaw }`, `LowGravity { scale }`, `Objective { id }`. Mirroring transforms jump-pad velocity, teleporter target and yaw; objective ids are kept.
- Weather calendar: list of `(from_s, weather)` entries, each lasting until the next.
- Lights: `(at, color linear RGB, intensity, range m)`.
- Prefabs: `(name, brushes, props, place: [(at: grid offset, turns: quarter turns)])`; placement rotates about the prefab origin then offsets. Expansion appends after the map's own items, in prefab then placement order.
- `expand_symmetry` expands prefabs first and appends the mirrored copies after the originals; the result declares `symmetry: None`. Mirrored zero coordinates are normalised to `+0.0`; yaws are normalised to `[0, 360)`.
- Migration chain is text based (`fn(&str) -> Result<String, MapError>`, one step per version); version 0 or above `FORMAT_VERSION` is `UnknownVersion`. Unknown fields are `MapError::Parse`. `MapError::Invalid` covers non-UTF-8 text and structural errors (degenerate boxes, bad player range, prism with < 3 points, cylinder with < 3 sides, stairs with 0 steps, duplicate prefab names, non-finite numbers); layout rules stay in lot 3.3.
- Added a root `.gitattributes` forcing LF on `assets/maps/*.ron`, needed for the byte-identical round trip on Windows checkouts with `core.autocrlf=true`.
