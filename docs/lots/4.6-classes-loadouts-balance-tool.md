# Lot 4.6 — Classes, loadouts, quirky weapons, balance tool
- Model/effort: Sonnet, medium, then Haiku for the data files | Depends on: 4.5 | Milestone: none

## Goal
Define the six starting classes and their weapons as RON data, add the quirky gadgets, and provide `xtask balance` which prints the time-to-kill (TTK) of every weapon-class pair.

## Crates
- Owned: `mode-fps` (class and loadout types, loader), `xtask` (`balance` subcommand), data files under the mode's data directory (proposed: `mode-fps/data/classes/*.ron`, `mode-fps/data/weapons/*.ron`; report the chosen path).
- Read-only: `minigame-api`, `sim`, `core`, `mapfmt`.
- Forbidden: public interfaces of `minigame-api`, `sim`, `core`, `mapfmt`.
- Haiku may write the RON data files and the table in the report only; Sonnet owns the types and the tool.

## Spec
### Starting classes (indicative; tuned by `xtask balance`)
| Class | Health | Speed factor | Main weapon | Trait |
|---|---|---|---|---|
| Trooper | 100 | 1.00 | assault rifle, 24 dmg, 600 rpm | all-round |
| Sprinter | 85 | 1.12 | submachine gun, 17 dmg, 900 rpm | double jump |
| Bruiser | 130 | 0.92 | pump shotgun, 8 pellets of 12 dmg | resistant |
| Marksman | 80 | 1.00 | precision rifle, 95 dmg, headshot fatal | scope |
| Boomer | 110 | 0.95 | rocket launcher, 90 area dmg | explosive jump |
| Prankster | 95 | 1.05 | rubber-chicken launcher, bouncing projectiles | quirky arsenal |
Speed factor multiplies the base run speed (7.0 m/s). Target TTK: 0.4 to 0.8 s for the starting pairs.

### Quirky weapons and gadgets (planned)
Banana peel (forces a slide), confetti cannon (blinds), baguette (melee), toaster (explosive toasts), bubble gun (slowing pistol). Rubber-chicken launcher belongs to Prankster.

### Weapon data
Same fields as lot 4.4 (type, fire mode, rpm, pellets, damage, falloff, magazine, spread, recoil, projectile, explosion). Every class has one main weapon; loadouts may add one secondary from a list.

### TTK formula (`xtask balance`)
For weapon w and class c with health PV and damage per hit D at body range:
TTK = (ceil(PV / D) - 1) * 60 / rpm.
Interpretation to confirm and report: for pellet weapons D is the total body damage of one trigger pull; for single-shot weapons with headshot-fatal rules, the tool also prints the head-shot TTK (= 0 for one-hit kills).
Check values: Trooper 100/24 gives 4 shots, 0.4 s. Sprinter 85/17 gives 4 gaps at 900 rpm, 0.267 s, which is below the target band and must be tuned.

## Public interfaces to create or respect
- `ClassDef`, `LoadoutDef`, `WeaponDef` loaders (serde RON), validated at load time: unknown fields and missing weapons are errors (`thiserror`).
- `xtask balance [--format text|csv]` reads the RON files and prints a matrix weapon x class of TTK in seconds, marking pairs outside 0.4 to 0.8 s.

## Acceptance criteria
- `cargo xtask balance` prints the TTK table; the table is committed in the lot PR description.
- `cargo xtask test` contains: loader rejects an unknown weapon reference; TTK formula check for Trooper = 0.4 s; the table is produced for all six classes.
- Every starting main-weapon pair is inside 0.4 to 0.8 s, or the deviation is listed in the report with the proposed value.
- `cargo xtask ci` is green.

## General conventions
Everything in the repo is English, including weapon and class names in data. Units: metre, second, radian. Right-handed, Y up, -Z forward. Data in RON, user settings in TOML. `thiserror` in libraries, `anyhow` in executables, `tracing` for logs. `unsafe` forbidden outside `render` and `upscale`. A lot never changes the public interface of a crate it does not own.
