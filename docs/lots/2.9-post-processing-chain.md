# Lot 2.9 — Post-processing: contours, bloom, tonemapping, grading, screen effects, FXAA
- Model/effort: Sonnet, moyen | Depends on: 2.3 | Milestone: none

## Goal
Implement the post-processing chain on the HDR colour buffer (contours, bloom, ACES tonemapping, grading, screen effects, FXAA), each effect switchable and driven by the ambience profile.

## Crates
- Owned: `render` (post passes, `PostSettings`); WGSL in `shaders`.
- Read-only: `core`. Forbidden: all other crates. Do not implement temporal AA (lot 2.10) here.

## Spec (condensed)
- Chain order (passes 5 and 7 of the frame; pass 6 upscaling is inserted between them in lot 2.10): contours -> bloom -> tonemapping -> grading -> screen effects. FXAA runs when temporal AA is off, as the fallback.
- Input: HDR `RGBA16F` colour, depth, normals `RG8`, motion `RG16F`.
- Contours: Sobel filter on linear depth and on normals; thickness and colour are parameters.
- Bloom: soft threshold, a chain of 6 downsamples, then filtered upsamples added back. Marked in profile `neon`.
- Tonemapping: approximate ACES filmic curve (plan form), applied per channel to the exposed value; exposure is from the profile:
```
T(x) = \frac{x\,(2{,}51x + 0{,}03)}{x\,(2{,}43x + 0{,}59) + 0{,}14}
```
  The plan's curve exceeds 1 above x ≈ 7.25 (asymptote ≈ 1.033). Decision: whether to clamp the output to [0,1] before grading is not in the plan; record it.
- Grading: lift, gamma, gain, saturation, hue shift (all parameters from profile).
- Screen effects: vignette, chromatic aberration, film grain, underwater ripple (from 2.8 flag), damage flash, speed lines. Each has an intensity parameter; 0 disables it.
- FXAA: standard FXAA on the tonemapped image, no temporal component.
- Every effect can be disabled from settings (`PostSettings` booleans; TOML loading is lot 6.4) and parameterised by the ambience profile.
- Ambient occlusion in screen space is optional and NOT in this lot's content list; leave it out.

## Public interfaces to create or respect
- `pub struct PostSettings { pub contours: bool, pub bloom: bool, pub tonemap: bool, pub grading: bool, pub screen_effects: bool, pub fxaa: bool }` (serde, defaults all true).
- `pub struct PostParams` (per-profile values: exposure, bloom threshold, grading, effect intensities).
- Post chain entry point used by the frame graph: `fn record_post(&mut self, ctx: &mut FrameCtx, input: ImageHandle) -> ImageHandle`.

## Acceptance criteria
- `cargo xtask render-test`: reference images for the full chain (`post_full.png`) and one image per toggle (`post_<effect>_off.png`) match within tolerance 1 per channel.
- Unit: T(0) = 0; monotonic increasing on [0, 16]; T(x) < 1 for x in [0, 7]. The criterion "T(x) < 1 for all x" cannot hold for the plan's curve (see Tonemapping), so it is restricted and recorded as a deviation.
- Unit: each effect with intensity 0 or flag false yields a pass-through result within tolerance.
- Unit: FXAA leaves a flat image unchanged.
- Zero validation-layer messages.

## Out of scope
Temporal anti-aliasing and reprojection (2.10), upscaling (2.10-2.12), screen-space ambient occlusion, lens distortion beyond the listed effects, HUD (lot 2.16, drawn after upscaling).
