# Lot 8.2 - Far landscape: LOD for vegetation and props, landmarks, atmosphere (phase 8, world)

Not in the reference plan. Phase 8 turns the arena maps into believable worlds (see `README.md`).

- **Model/effort:** Opus, high | **Depends on:** 8.1 | **Branch:** `lot/8.2-far-landscape-lod` (one PR)
- **Owns:** `render` (instancing LOD, impostors, atmosphere), `client::landscape`. Additive changes allowed in `mapfmt`, `assets`.

## Goal

The horizon is full and readable: forests, hills and recognisable landmarks, at a small frame cost.

## Spec

1. Vegetation and prop **LOD chain** (mesh LOD, then billboard impostors, then merged far forest mass), GPU or chunked CPU culling (decision: record it), shared with the terrain chunks of 8.1.
2. **Landmarks:** each map can declare a few big distant structures (mountain, city skyline, bridge, lighthouse, tower) generated by recipes, always drawn with a cheap LOD.
3. **Aerial perspective:** distance fog tinted by sky, height fog in valleys, soft sun scattering; per-theme profiles built on the lot 2.4 ambience system.
4. Stable frame time with a 2 km view: budget and benchmark added to the perf tests.

## Acceptance

`cargo xtask ci` green; lavapipe screenshots of a far forest and of a landmark; LOD transition test (no pop above a set threshold); the dense-world benchmark stays inside the frame budget.
