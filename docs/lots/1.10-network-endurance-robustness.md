# Lot 1.10 — Endurance and network robustness tests
- Model/effort: Sonnet, medium | Depends on: 1.7 | Milestone: none

## Goal
Prove that the network stack survives malformed input and long runs: no panic, no leak, stable for 10 minutes, with all network criteria met under degraded conditions.

## Crates
- Owns: the test suites (`tests/` directories) of `protocol`, `net`, `server`, `client`.
- Read-only: every crate under test. External: `proptest`, `cargo-nextest`.
- Forbidden: changing any public interface, and changing production code except to fix a defect found by these tests (report such fixes explicitly).

## Spec
Test types (section 20):
- Robustness: random bytes and truncated copies of valid packets sent to the server through a transport. The server must never panic; decoding returns `Err`. Also check the per-client rate limit and the rejection of maps above 256 KiB (section 6, guard rails).
- Network integration: one server and several headless clients in one process, 100 ms latency, 20 ms jitter, 5 % loss.
- Endurance: 16 bots for 10 minutes of simulated time, with no panic and no memory leak (memory stable after warm-up).

Criteria measured in tests (section 20):
- Mean prediction error below 5 cm under the degraded conditions above.
- Downlink below 100 kbit/s per client at 16 players.
- No lasting state divergence between client and server.

## Public interfaces to create or respect
- None created. Tests use the existing public API only.

## Acceptance criteria
- Robustness test: at least 10 000 random and truncated inputs, no panic (proptest). The count is a lot decision; the plan gives no number.
- Integration test passes all three criteria above.
- Endurance: an ignored-by-default test, run with `docker compose run --rm dev cargo nextest run --run-ignored all -E 'test(endurance)'`, completes 10 minutes of simulated time with 16 bots, no panic, memory growth stable (report the figures).
- `docker compose run --rm dev cargo xtask test` passes (ignored endurance test excluded).
- Milestone check: a 10-minute run is reported as stable.

## Out of scope
New features, performance tuning (phase 7), rendering tests (phase 2), mode rules.
