# Lot 2.2 — Meshes, instances, camera, reverse-Z, jitter, motion vectors, culling
- Model/effort: Opus, moyen | Depends on: 2.1 | Milestone: none

## Goal
Render static meshes as instances with a reverse-Z infinite projection, sub-pixel jitter, per-pixel motion vectors and CPU frustum culling, so a cube scene matches its reference.

## Crates
- Owned: `render`.
- Read-only: `core` (glam, ids), `assets` (mesh data types only if already defined there; otherwise use local test arrays). Do not change them.
- Forbidden: all other crates.

## Spec (condensed)
- Vertex, exactly 20 bytes: position 3 x f32 (12 B), normal 4 x i8 normalised (4 B), 4 x u8 for colour and material id (4 B; assumed layout: r, g, b, material_id — record any change). Add a `const` assert on size.
- Flat shading: vertices duplicated per face. Smoothing groups exist for weapons (lot 2.15), not here.
- Static geometry lives in one large vertex and index arena. Per-instance data is rewritten every frame.
- CPU frustum culling: box test against the six camera planes. Target: fewer than 500 draw calls per frame.
- Projection: reverse-Z, infinite far plane, depth `D32_SFLOAT`, clear value 0, compare `GREATER_OR_EQUAL`. With f = 1/tan(fov/2), aspect a, near n (plan section 8; the `-f` in row 2 is the Vulkan y-down flip). Do not use `glam::Mat4::perspective_infinite_reverse_rh` as is: it has no y flip. Build P explicitly:
```
P = \begin{pmatrix} f/a & 0 & 0 & 0 \\ 0 & -f & 0 & 0 \\ 0 & 0 & 0 & n \\ 0 & 0 & -1 & 0 \end{pmatrix} \qquad z_{ndc} = \frac{n}{-z_{vue}}
```
- Jitter: Halton sequence bases 2 and 3, 16 samples, index = frame_index mod 16; H_k is the k-th value. Plan form (x uses width, y uses height):
```
j_k = \frac{2\,(H_k - 0{,}5)}{\text{r\'esolution}}
```
Add j_x to P[2][0] and j_y to P[2][1]. The sign of this addition is not fixed by the plan: decision, document it.
- Motion vectors `RG16F`: computed from current and previous clip positions WITHOUT jitter (c = current, c' = previous). Each instance supplies its previous matrix. Plan form:
```
\vec{m} = \tfrac{1}{2}\left(\frac{c_{xy}}{c_w} - \frac{c'_{xy}}{c'_w}\right)
```
- Opaque pass outputs: HDR colour `RGBA16F`, depth `D32_SFLOAT`, motion `RG16F`, normals `RG8`.
- Frame boundary: `RenderWorld` = camera (view, unjittered and previous projection, jitter), instances (mesh id, material id, current and previous model matrix), lights (empty until 2.4), ambience (empty until 2.4).

## Public interfaces to create or respect
- `pub struct Camera { view: Mat4, proj: Mat4, prev_view_proj: Mat4, jitter_px: Vec2 }` (glam types).
- `pub struct Instance { mesh: MeshId, material: u8, world: Mat4, prev_world: Mat4 }`.
- `pub struct RenderWorld` extended: `camera`, `instances: Vec<Instance>`, `clear_color` (kept from 2.1).
- `pub fn jitter(frame_index: u32) -> Vec2` (Halton 2/3, 16 samples) — reused by lot 2.10 via the `Upscaler` trait.
- Respect `render::Renderer::render_frame(&RenderWorld)` from 2.1.

## Acceptance criteria
- `cargo xtask render-test`: cube scene (grid of cubes, one directional tint per face) matches `render/tests/refs/cubes.png` within tolerance 1 per channel.
- Unit: `size_of::<Vertex>() == 20`.
- Unit: Halton values for indices 1..=16 match reference to 1e-6.
- Unit: culling test with 10 000 instances, 90 % outside the frustum: draw count equals visible count, and is below 500 for the visible set.
- Unit: static camera and static instances give motion vectors of exactly 0; a camera translated by a known amount gives the expected sign and magnitude.
- Depth test: a near object occludes a far one with reverse-Z; far plane at infinity clips nothing.
- Zero validation-layer messages in `render-test`.
- `cargo xtask build` succeeds for the Windows and Linux x86_64 targets.

## Out of scope
Lighting, shadows, sky, materials and WGSL patterns (2.3-2.4), smoothing groups, mesh loading from RON (2.13), map block merge at 16 m (3.2), ambient occlusion, temporal upscaling (2.10).
