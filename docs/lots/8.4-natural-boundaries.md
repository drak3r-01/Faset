# Lot 8.4 - Natural boundaries and playable zone (phase 8, world)

Not in the reference plan. Phase 8 turns the arena maps into believable worlds (see `README.md`).

- **Model/effort:** Sonnet, high | **Depends on:** 8.1, 8.3 | **Branch:** `lot/8.4-natural-boundaries` (one PR)
- **Owns:** `mapfmt` (zone mask), `sim` (boundary rule), `bots` (navigation limit), `client` (feedback). Additive.

## Goal

No invisible walls: the playable zone is closed by the scenery itself.

## Spec

1. **Zone mask** in the map file: the playable area is any shape, not only a rectangle (cliff ring, riverbank, ravine, forest wall, sea).
2. **Boundary generator** that shapes the relief at the edge: cliffs, steep banks, dense blocking forest, deep water; the validator rejects a zone that can be left on foot.
3. **Simulation keeps the hard rule** (soft push-back then kill outside the mask) with a short on-screen warning; same code on server and prediction.
4. Bots navigate only inside the mask; map-tool reports when the zone leaks.

## Acceptance

`cargo xtask ci` green; test that no player can leave on the proof maps, including by jumping and sprinting along walls; validator test of a leaky zone; bot trial unchanged.
