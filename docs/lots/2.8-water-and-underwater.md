# Lot 2.8 — Water surface and underwater medium
- Model/effort: Sonnet, moyen | Depends on: 2.4 | Milestone: none

## Goal
Render a water surface displaced by a sum of Gerstner waves and an underwater medium (dense blue-green fog, caustics, suspended particles); an underwater reference must match.

## Crates
- Owned: `render` (water pass, underwater state); WGSL in `shaders`.
- Read-only: `core`. Forbidden: all other crates. Underwater image ripple is a post effect owned by lot 2.9; this lot only exposes the flag.

## Spec (condensed)
- Surface displacement: sum of Gerstner waves (plan form). Wave i has amplitude A_i, steepness Q_i in [0,1], unit direction D_i (2D), wavelength λ_i, wavenumber k_i = 2π/λ_i, and x0 the rest position:
```
x \mathrel{+}= \sum_i Q_i A_i\, D_i \cos(k_i\, D_i \cdot x_0 - \omega_i t) \qquad y \mathrel{+}= \sum_i A_i \sin(k_i\, D_i \cdot x_0 - \omega_i t)
```
- Dispersion (plan form): ω_i = √(g k_i). The plan gives no value for g: decision, g = 9.81 m/s².
- Normals from the analytic partial derivatives of the sum.
- Underwater medium (when the camera is below the surface): exponential fog with dense blue-green colour (profile `underwater`); height fog from 2.4 is replaced.
- Caustics: procedural animated pattern projected onto lit surfaces (animated cell-noise, two layers offset in time), filtered with `fwidth` to avoid shimmer at distance.
- Suspended particles: stateless, same technique as lot 2.7.
- Set the underwater flag in `RenderWorld` when the camera y is below the water height in the map.

## Public interfaces to create or respect
- `pub struct WaterParams { pub height: f32, pub waves: Vec<GerstnerWave> }`, `pub struct GerstnerWave { pub amplitude: f32, pub steepness: f32, pub direction: Vec2, pub wavelength: f32 }` (serde).
- `pub fn gerstner_displace(p: Vec2, t: f32, waves: &[GerstnerWave]) -> (Vec3, Vec3)` (position, normal), CPU mirror for tests.
- `RenderWorld` gains `underwater: bool`.

## Acceptance criteria
- `cargo xtask render-test`: underwater reference scene `profile_underwater.png` matches within tolerance 1 per channel.
- Unit: `gerstner_displace` with a single wave of steepness 0 gives a pure sine height: max error 1e-6 vs `A·sin`.
- Unit: dispersion check: ω(λ) matches sqrt(g·2π/λ) within 1e-6.
- Unit: normals are unit length within 1e-4 for steepness up to 1 with the waves in the test set (no fold-over; steepness constraint Σ Q_i·k_i·A_i <= 1 enforced, otherwise error).
- Unit: `underwater` flag is true exactly when camera y < water height.
- Zero validation-layer messages.

## Out of scope
Buoyancy and swimming physics (sim, phase 4), waves that affect gameplay, reflections beyond the sky term, foam, underwater image ripple (lot 2.9), shore interaction.
