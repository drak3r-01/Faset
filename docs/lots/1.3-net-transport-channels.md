# Lot 1.3 — net: Transport trait, UDP, memory transport, network conditions simulator, channels
- Model/effort: Sonnet, high | Depends on: 1.1 | Milestone: none

## Goal
Provide a `Transport` abstraction with UDP, in-memory and condition-simulating implementations, and the four network channels, proven reliable and unreliable under 10 % packet loss.

## Crates
- Owns: `net`.
- Read-only: `protocol` (message types), `core`.
- External: `renet` (connections and channels; choice confirmed in this lot). If `renet` fails the criteria, replace it only inside `net`, without changing the public trait.
- Forbidden: every other crate.

## Spec
Section 6, transport:
- Trait `Transport` with three implementations: UDP (real sockets), memory (used by the integrated server, lot 1.9), and a wrapper that simulates latency, jitter, loss, duplicates and reordering (for tests).
- Maximum payload 1200 bytes per packet (avoids IP fragmentation).
- Non-blocking reads (the server reads sockets at the start of each tick; no async runtime).

Channels:
| Channel | Direction | Reliability | Content |
|---|---|---|---|
| 0 | client to server | unreliable | input commands |
| 1 | server to client | unreliable | snapshots |
| 2 | both | reliable, ordered | events: deaths, score, phases, map change, chat |
| 3 | server to client | reliable, chunked | map transfer |

Simulator parameters (all configurable): latency (ms), jitter (ms), loss (%), duplication (%), reordering. Integration tests elsewhere use 100 ms latency, 20 ms jitter, 5 % loss.

## Public interfaces to create or respect
- `trait Transport`: send and receive of packets on a channel, non-blocking poll.
- `UdpTransport`, `MemoryTransport` (paired endpoints), `ConditionedTransport<T>` wrapping any transport, with a config struct for the parameters above.
- Channel identifiers as an enum or constants matching the table.

## Acceptance criteria
- Under 10 % loss: channel 2 delivers every message, in order (test).
- Under 10 % loss: channel 3 delivers a 256 KiB payload intact (checksum equal) (test).
- Channel 0 under 10 % loss: no retransmission; delivered count within the expected binomial range (test).
- Memory transport and UDP over loopback pass the same test suite.
- No packet sent is larger than 1200 bytes (test).
- `docker compose run --rm dev cargo xtask test` passes.

## Out of scope
Game message semantics (lot 1.1), snapshot logic (1.4, 1.5), server loop (1.4), discovery broadcast (1.9), NAT traversal (not in scope at all).
