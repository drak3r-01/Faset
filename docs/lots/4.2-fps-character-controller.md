# Lot 4.2 — Full character controller
- Model/effort: Opus, high | Depends on: 1.6, 3.2 | Milestone: J3 (this lot)

## Goal
Implement the complete Quake-style character controller in `sim` (ground, air, bunny hop, jump buffer, coyote time, slide base, collision sweep with steps and snapping), deterministic and shared by client prediction and server.

## Crates
- Owns: `sim` (new module `controller`, plus its tests and trace files).
- Read-only: `core`, `protocol` (input command types), `mapfmt`, `sim::map_collision` (from 3.2).
- Forbidden: `net`, `server`, `client`, `render`, `minigame-api`, `mode-*`. Changing `sim::map_collision` public API is forbidden (stop and report).

## Spec (condensed from plan sections 15, 5, 6)
Tick: `DT = 1/60 s`, fixed. Same code on client and server.

Parameters (RON file, tunable without recompiling):
| name | symbol | value |
|---|---|---|
| run speed | v_run | 7.0 m/s |
| ground accel | a_g | 10 s⁻¹ |
| ground friction | f | 6 s⁻¹ |
| stop speed | v_stop | 2.0 m/s |
| air accel | a_a | 10 s⁻¹ |
| air wish cap | w_air | 0.8 m/s |
| gravity | g | 20 m/s² |
| jump speed | v_j | 6.5 m/s |
| slide friction | f_slide | 0.8 s⁻¹ |
| slide impulse | b | 2.5 m/s |
| max step | — | 0.45 m |
| max walkable slope | — | 45° |
| safety speed cap | — | 30 m/s |
Derived checks: jump height 1.06 m, air time 0.65 s, run-speed jump range 4.55 m.
Capsule: radius 0.35 m, height 1.8 m (crouch 1.0 m). Eye height 1.6 m (0.8 m crouched, smoothed).
Input quantisation (both sides): yaw `u16`, step 2π/65536; pitch `i16`; move axes `i8`; buttons `u16` bitfield. Input is simulated after quantisation.

Movement:
- Wish direction (plan section 15; axes projected on the horizontal plane by yaw only; `F̂_h` forward, `R̂` right):
```
\hat{w} = \mathrm{normalize}\big(m_z\,\hat{F}_h + m_x\,\hat{R}\big) \qquad w = v_{run} \cdot \min(1, |m|)
```
- Ground friction, only if on ground and not jumped this tick (plan section 15):
```
s = |v_h| \qquad c = \max(s, v_{stop}) \qquad v_h \leftarrow v_h \cdot \frac{\max(s - c\,f\,\Delta t,\ 0)}{s}
```
- Acceleration, same function on ground and air (only coefficient and cap change):
```
p = v \cdot \hat{w} \qquad \Delta = w_{max} - p \qquad \text{si } \Delta > 0:\quad v \leftarrow v + \min(a\, w\, \Delta t,\ \Delta)\,\hat{w}
```
  Ground: `a = a_g`, `w_max = w`. Air: `a = a_a`, `w_max = min(w, w_air)`. The product `a w Δt` uses the uncapped wish speed.
- Bunny hop (`s = a_a w Δt`): in air only the projection p is bounded, so a lateral wish gives:
```
|v'|^2 = |v|^2 + 2s\,p + s^2 \qquad \text{maximum at } p = w_{air} - s:\quad |v'|^2 = |v|^2 + 2s\,w_{air} - s^2
```
  Gain per tick about `(2 s w_air − s²) / (2|v|)`; plan figure: about +1.4 m/s per jump at run speed.
- Jump: if requested while touching ground, it fires the same tick and friction is skipped (speed kept between jumps). Request buffer 100 ms. Coyote time 80 ms after leaving a ledge.
- Auto-hop: holding jump re-jumps on landing (server rule, switchable).
- Soft brake: above 15 m/s, each landing removes a configurable fraction of the excess (RON parameter).
- Ground test: sweep 5 cm down; a surface is ground if `n_y ≥ 0.707` (45°). Steeper surfaces are not ground; velocity projection slides along them.
- Move: sweep capsule along remaining `v·DT`, up to 4 iterations per tick. On contact advance to impact minus 1 mm, remove velocity component toward the surface. Two edge surfaces: project onto their intersection. Three: stop.
```
v \leftarrow v - (v \cdot n)\,n \qquad \text{edge}:\ v \leftarrow \big(v \cdot \hat{d}\big)\,\hat{d},\quad \hat{d} = \mathrm{normalize}(n_1 \times n_2)
```
- Steps: if blocked, retry raised by 0.45 m then lowered; keep the longer horizontal result.
- Snap down: a grounded player is pulled down up to 0.3 m, unless he just jumped.
- Gravity: two half-steps, one before and one after the move, so jump height does not depend on tick rate (plan section 15):
```
v_y \leftarrow v_y - \tfrac{1}{2} g\,\Delta t \quad\rightarrow\quad \text{move} \quad\rightarrow\quad v_y \leftarrow v_y - \tfrac{1}{2} g\,\Delta t
```
- Safety: speed never exceeds 30 m/s; no wall crossing at max speed.

Tick order per player: read command, wish direction; update crouch, slide, timers; ground test; jump handling; friction (if ground and no jump); acceleration by state (ground, air, slide); gravity half-step; move with collision and steps; gravity half-step; ground test and landing event; zone triggers (zone effects come in 4.3).

Tests required: recorded command sequences replayed and compared to reference positions; bunny hop with lateral input exceeds 1.5 × v_run (10.5 m/s) within ten jumps; the same script without lateral input gains nothing; no wall crossing at max speed; speed never above 30 m/s.

## Public interfaces to create
- `sim::controller::PlayerState { pos, vel, on_ground, crouched, slide_timer, jump_buffer, coyote_timer, ... }`.
- `sim::controller::MoveCmd` (quantised), `step_player(state: &mut PlayerState, cmd: MoveCmd, world: &MapCollision, params: &MoveParams, dt: f32) -> MoveEvents` (landing, jump).
- `MoveParams` loaded from RON; defaults equal the table above.
Milestone J3 is this lot: the controller must be usable by the prediction loop (1.6) without change.

## Acceptance criteria
- `cargo xtask test`: all tests in the Tests paragraph pass; replay of recorded traces is bit-identical on two runs on the same host.
- Ground test rejects surfaces steeper than 45°.
- `cargo xtask check` passes.

## Out of scope
Slide, slide-hop, wall jump, trampolines, zones (4.3), weapons and recoil, double jump (class feature, later), prediction and reconciliation loop (1.6), network transport.

## Decisions and deviations (recorded at delivery)
- Parameters: `crates/sim/data/move_params.ron` (embedded as `DEFAULT_PARAMS_RON`, equal to `MoveParams::default()`; missing fields default, unknown fields rejected). Extra parameters beyond the table: jump buffer 0.1 s, coyote 0.08 s, auto-hop on, soft brake above 15 m/s removing 25 % of the excess, ground probe 0.05 m, snap-down 0.3 m, crouched ground speed x0.5, eye smoothing 8 m/s.
- Buttons: bit 0 jump, bit 1 crouch (`BUTTON_JUMP`, `BUTTON_CROUCH`); `MoveCmd: From<InputCommand>`.
- Grounded players get no gravity and zero vertical speed; the jump tick uses air acceleration; rising players cannot land; timers are active while above half a tick (buffer 6 ticks, coyote 4 ticks).
- Ground uses the face normal under the contact (short ray), so a step edge counts as the step top; grounded players treat non-walkable contacts as vertical walls; a step must land with its touched point at most 0.45 m above the feet.
- Deviation: parry sweeps near large map boxes are only accurate to a few millimetres (and can miss when they start in contact), so flat ground is measured with an exact ray and contacts are settled back to the 1 mm skin with exact rays. Tests bound penetration by 5 mm instead of 0.
- Yaw sine/cosine come from fixed polynomials (no platform libm) so clients and servers on different OSes agree.
- Slide: only `slide_timer` and the two parameters exist (out of scope).
- `World::with_controller` makes `World::step` use the controller (opt-in). The stub stays the default: the client prediction tests (lot 1.6, crate `client`, forbidden here) assume the 5 m/s stub, and `Prediction` respawns from a position only, which would lose velocity and timers. Switching server and client needs a lot that owns them; `World::controller_state` / `set_controller_state` exist for the prediction restore. `Trace::replay_controller` replays traces with the controller.
