# Lot 6.1 — Application states, main menu, loading
- Model/effort: Sonnet, medium | Depends on: 4.1, 2.16 | Milestone: none

## Goal
The client has a stacked state machine and all main screens, so every screen can be reached and left.

## Crates
- Owned: `client` (state machine), `ui` (menu and loading screens).
- Read-only: `minigame-api` (mode registry), `sim`, `render`, `core`, `net`, `editor`.
- Forbidden: changing public interfaces of read-only crates.

## Spec
States: `Boot`, `MainMenu`, `ServerBrowser`, `HostSetup`, `Loadout`, `Settings`, `Connecting`, `Loading`, `InGame`, `Editor`.
- Managed as a stack. Settings and the pause menu are pushed on top of `InGame` without destroying the match; popping returns to the same world.
- Main menu (Accueil): play, join, classes, editor, settings, quit, over a slowly rotating map background.
- Play screen: mini-game choice (from the registry), maps or rotation, bot count and level, max players, LAN opening, password, mode settings.
- Join screen: LAN servers, connect by address, favourites and history (content completed in lot 6.2).
- Classes screen: creation and customisation (content in lot 6.3).
- Pause, in game: resume, classes, settings, leave match.
- Loading screen shown while a map loads (target < 2 s, section 20).
- Menus list registered mini-games from the registry; nothing is FPS-specific in this layer.

## Public interfaces to create or respect
- `client`: `AppState` enum, `StateStack` with `push`, `pop`, `replace`, and transition events.
- `ui`: one screen function per state, receiving `&mut StateStack` through a command enum (no direct world access).

## Acceptance criteria
- `dev.ps1 test` passes:
  - a state-machine test drives every state in the list and returns to `MainMenu`;
  - pushing `Settings` on `InGame` then popping restores the same world instance id and entity count;
  - the menu lists every mode in the test registry, and only those.
- Headless render check (`dev.ps1 render-test`): main menu renders on lavapipe without validation errors.
- `dev.ps1 ci` passes.

## Out of scope
- Hosting and joining logic (6.2); loadout content (6.3); settings content (6.4, 6.5); the test mode of lot 4.1 stays unchanged.
