# Lot 5.2 — Editor: camera, selection, handles, volume creation, undo
- Model/effort: Sonnet, high | Depends on: 3.3, 2.16 | Milestone: none

## Goal
A map can be built and fully undone step by step inside the editor, with edits saved exactly as they are shown.

## Crates
- Owned: `editor`.
- Read-only: `mapfmt` (`Map` structure, brushes), `render` (camera, `RenderWorld`), `ui` (egui integration, theme), `sim`, `core`.
- Forbidden: changing public interfaces of read-only crates; stop and report if needed.

## Spec
- The editor is a client state `Editor`. Its document is directly the `mapfmt::Map` structure: what is edited is what is saved.
- Every modification is a command with `apply` and `revert`, pushed on an undo history. Undo pops and reverts; redo is optional.
- Rebuild: only the 16 m blocks touched by a command are regenerated (not the whole map).
- Camera: free fly, and orthographic top view (toggle).
- Selection: ray under the cursor tested against volumes and props (props via their bounds).
- Handles on the selection: move, rotate, scale. Snap to a 0.5 m grid and to 15° angles.
- Axis handle drag: the point on the handle axis (P1, d1) closest to the mouse ray (P2, d2), with r = P1 − P2. Parameter s, new point = P1 + s·d1:
```
s = \frac{(d_1 \cdot d_2)(d_2 \cdot r) - (d_2 \cdot d_2)(d_1 \cdot r)}{(d_1 \cdot d_1)(d_2 \cdot d_2) - (d_1 \cdot d_2)^2}
```
  If the denominator ≈ 0 (parallel rays), keep the previous position (decision). Unit-test this formula.
- Volume creation: drag a rectangle on the ground, then pull the height. Brushes: `Box`, `Wedge`, `Cylinder`, `Prism`, `Stairs`.
- Coordinates are integer half-metres (0.5 m grid), as the format requires.
- UI in `egui` at display resolution.

## Public interfaces to create or respect
- `editor`: `Command` trait (`apply`, `revert`), `History` (push, undo), `EditorState`, camera modes, snap settings.
- Respect `mapfmt::Map` and `render` camera types as they are.

## Acceptance criteria
- `dev.ps1 test` passes:
  - a room made of at least 3 brushes is built through commands, then undone command by command; after each undo the serialized RON equals the state before that command (byte-equal);
  - snapping: positions snap to 0.5 m; angles snap to 15°;
  - axis-drag formula test, including the parallel fallback;
  - a single brush edit rebuilds only the blocks it touches (counted by a test hook).
- `dev.ps1 ci` passes.

## Out of scope
- Library, props placement UI, gameplay points, ambiance, symmetry (lot 5.3); validation, test launch, file I/O (lot 5.4).
