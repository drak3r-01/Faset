# Lot 2.5 — Cascaded sun shadows
- Model/effort: Sonnet, élevé | Depends on: 2.4 | Milestone: none

## Goal
Add three-cascade sun shadow maps with texel snapping and 3x3 filtering, so shadows are stable while the camera moves.

## Crates
- Owned: `render` (shadow pass, cascade code); WGSL shadow functions in `shaders`.
- Read-only: `core`. Forbidden: all other crates.

## Spec (condensed)
- Pass 1 of the frame: render depth into 3 cascade maps, each 2048 x 2048, format `D32_SFLOAT`, reverse-Z consistent with the main camera (or documented otherwise).
- Only the sun casts shadows; point lights do not.
- Cascade split (plan form, N = 3 cascades, n = near, f = far, λ = 0.7). Splits are d_1, d_2, d_3 (d_0 = n, d_3 = f):
```
d_i = \lambda\, n \left(\frac{f}{n}\right)^{i/N} + (1 - \lambda)\left(n + \frac{i}{N}(f - n)\right) \qquad \lambda = 0{,}7
```
- Each cascade is fitted to a bounding sphere of its frustum slice (rotation-invariant, so size does not change when the camera turns).
- Texel snapping: texel size = 2 · sphere_radius / 2048. Round the light-space origin of each cascade to whole texels so edges do not shimmer when the camera moves.
- Filtering: 3 x 3 percentage-closer filter in the main shader.
- Bias: slope-scaled depth bias plus normal offset; values are fields of the ambience profile.
- Output: shadow occlusion `o` in [0,1] feeds the lighting formula from lot 2.4.

## Public interfaces to create or respect
- `pub struct ShadowCascades { pub matrices: [Mat4; 3], pub splits: [f32; 3] }`, computed by `fn fit_cascades(camera: &Camera, sun_dir: Vec3, near: f32, far: f32) -> ShadowCascades`.
- `RenderWorld` unchanged publicly; sun direction comes from the ambience profile.

## Acceptance criteria
- Unit: `fit_cascades` returns splits strictly increasing and within [near, far].
- Unit: snapping: moving the camera by less than one texel leaves the snapped cascade matrix identical; moving by exactly k texels shifts the matrix by k texels.
- Unit: sphere radius is identical for two camera rotations at the same position.
- `cargo xtask render-test`: a stability test renders a shadowed scene while the camera moves in 0.5-texel steps; consecutive frames show zero shadow-edge pixel change in the static region, and the reference image `shadow_cascade.png` matches within tolerance.
- Zero validation-layer messages.

## Out of scope
Contact shadows, shadow maps for point lights, soft shadows beyond 3x3 PCF, ambient occlusion, cascade count other than 3.
