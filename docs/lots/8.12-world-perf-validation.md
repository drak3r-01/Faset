# Lot 8.12 - World performance and validation (phase 8, world)

Not in the reference plan. Phase 8 turns the arena maps into believable worlds (see `README.md`).

- **Model/effort:** Sonnet, medium | **Depends on:** 8.9, 8.10, 8.11 | **Branch:** `lot/8.12-world-perf-validation` (one PR)
- **Owns:** `render`, `client`, `mapfmt` (no public interface change), `docs`.

## Goal

The finished world runs inside the budgets on real hardware.

## Spec

1. Profile the seven rebuilt maps: frame time, GPU/CPU memory, streaming hitches, load time, map transfer size.
2. Fix the worst offenders (LOD distances, culling, chunk sizes) without changing public interfaces.
3. Re-run determinism, prediction and bot trial suites on all maps.
4. Record the numbers in `docs/` and update the quality presets (view distance, vegetation density) accordingly.

## Acceptance

`cargo xtask ci` green; benchmark table in the report; no map over its frame budget on the reference preset.
