# Lot 1.7 — Remote interpolation, history and lag compensation
- Model/effort: Opus, medium | Depends on: 1.6 | Milestone: none

## Goal
Display remote entities through Hermite interpolation at a deliberate delay, and let the server rewind other players' hitboxes to the shooter's view time (capped at 250 ms) so a shot at a target moving with 100 ms latency registers.

## Crates
- Owns: `client` (interpolation module), `server` (lag compensation module and collision history).
- Read-only: `sim`, `net`, `protocol`, `core`.
- Forbidden: every other crate. Do not change existing public interfaces of `server` outside the new module.

## Spec
Remote interpolation (section 6):
- Remote entities are shown with a deliberate delay so two snapshots always bracket the render time (`I` = snapshot interval, `j` = measured jitter from 1.6):
```
t_{rendu} = t_{serveur} - d \qquad d = \max(2I,\ I + 2j) \qquad I = \text{intervalle entre snapshots}
```
- Position: cubic Hermite interpolation using the positions and velocities of the two bracketing snapshots, with `s` in [0, 1] the fraction from snapshot 0 to snapshot 1. This gives correct jump arcs at 30 Hz:
```
p(s) = (2s^3 - 3s^2 + 1)\,p_0 + (s^3 - 2s^2 + s)\,I\,v_0 + (-2s^3 + 3s^2)\,p_1 + (s^3 - s^2)\,I\,v_1
```
- Angles: interpolate along the shortest path.
- Without a new snapshot: extrapolate for at most 0.25 s, then freeze the entity.

Lag compensation (section 6):
- The server keeps 1 s of history of each player's hitboxes: capsule for the body (radius 0.35 m, height 1.8 m, height 1.0 m when sliding), sphere for the head.
- A fire command carries the interpolation tick and fraction the shooter saw.
- The server checks that this instant is consistent with the shooter's measured latency, then clamps it to at most 250 ms in the past.
- It places the other players at that instant, interpolating between two history entries.
- It casts the ray from the shooter's authoritative position, then restores the positions.
- Slow projectiles are not compensated.

## Public interfaces to create or respect
- Interpolation buffer and sampling function for remote entities.
- Server history ring (1 s per player) and `rewind_and_cast(shooter, fire_command)` (or equivalent).

## Acceptance criteria
- Test: target moving at constant speed, shooter latency 100 ms, shot aimed at the displayed position: hit registered.
- Test: a shot claiming an instant 300 ms old is clamped to 250 ms.
- Proptest: Hermite output equals the endpoints at t = 0 and t = 1; extrapolation stops after 0.25 s.
- Restore test: all positions are back to their authoritative values after a rewound cast.
- `docker compose run --rm dev cargo xtask test` passes.

## Out of scope
Projectile simulation and replication (later), damage rules (section 16), prediction (1.6), rendering of remote players.
