# Lot 6.2 — Host with bots and LAN, join, LAN list, favourites
- Model/effort: Sonnet, medium | Depends on: 6.1, 1.9, 4.10 | Milestone: none

## Goal
A player can host (with bots, optionally on LAN) and join from the menus: LAN list, address, favourites.

## Crates
- Owned: `ui` (HostSetup and ServerBrowser screens), `client` (host/join flows and favourites file).
- Read-only: `server` (library, LAN discovery from lot 1.9), `net`, `protocol`, `bots`, `minigame-api`, `core`.
- Forbidden: changing public interfaces of read-only crates. Wiring a missing server function means stop and report.

## Spec
Host (Play screen, `HostSetup`):
- mini-game, maps or rotation, bot count and level, max players (default 16; capacity 16 with a technical margin to 32), LAN opening toggle, password, mode settings.
- Hosting starts the integrated server (memory transport) in a dedicated thread; with LAN on, adds the UDP transport on game port 7777.
- Solo with bots = integrated server not opened.

Join (`ServerBrowser`):
- LAN list: client broadcasts a discovery request on UDP port 7778 on each interface; servers answer with name, mode, map, players present/max, port.
- List refreshes every 2 s; an entry expires after 6 s without a reply.
- Connect by address (`host:port`, default port 7777).
- Favourites and history. Store favourites as RON in the data folder (plan does not fix the file name; use `favorites.ron` and record it in the report).
- Password is checked by the existing protocol handshake; wrong password is refused with a message.

Windows firewall prompt on first LAN use is expected; no code action.

## Public interfaces to create or respect
- `client`: `HostConfig` (built from the setup screen), `JoinTarget` (address or LAN entry), `Favorites` load/save.
- `ui`: `ServerBrowser` view model with entries and expiry.

## Acceptance criteria
- `dev.ps1 test` passes:
  - hosting with 4 bots starts a match; a client joins through the LAN list on loopback (UDP 7778 discovery answered);
  - an LAN entry disappears 6 s after its last reply on a simulated clock;
  - favourites survive save and reload;
  - wrong password is refused; right password joins.
- `dev.ps1 ci` passes.

## Out of scope
- Master server, internet directory, NAT traversal, host migration (section 7 forbids them).
