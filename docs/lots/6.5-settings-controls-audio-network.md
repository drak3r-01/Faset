# Lot 6.5 — Settings: controls, audio, network, game, accessibility, translation
- Model/effort: Sonnet, medium, then Haiku for the translated texts | Depends on: 6.4 | Milestone: none

## Goal
All remaining settings work and apply live; key rebinding detects conflicts; English and French UI are complete.

## Crates
- Owned: `ui` (controls, audio, network, game and accessibility screens), `core` (translation table loader, key bindings).
- Read-only: `audio` (bus volumes API), `client`, `net`, `server`, `render`, `core` settings schema from 6.4 (extend only the settings module this lot owns).
- Forbidden: changing public interfaces of read-only crates.

## Spec
Controls:
- sensitivity and aim sensitivity; invert; full rebinding of every action with conflict detection (assigning a bound key asks to swap or cancels);
- hold or toggle for crouch and for aim; hold jump; gamepad.
- Sensitivity also shown as centimetres for a full turn (section 19), `sens` = in-game sensitivity, `dpi` = mouse dpi (the constant 0.022 is taken as written in the plan):
```
\mathrm{cm}/360 = \frac{360 \times 2.54}{0.022 \times \mathrm{sens} \times \mathrm{dpi}}
```

Audio (engine `kira`, separate buses, 32 simultaneous voices with priorities):
- volumes: master, effects, UI. No music volume: no music at all (section 22 final decisions); effects are synthesised;
- output device; key sound.

Network:
- pseudonym; snapshot frequency (20 to 60 Hz, default 30 Hz); interpolation delay automatic or manual; port; LAN discovery toggle; network graph toggle.
- Automatic interpolation delay (section 6), `I` = interval between snapshots, `j` = smoothed jitter:
```
t_{rendu} = t_{serveur} - d \qquad d = \max(2I,\ I + 2j) \qquad I = \text{interval between snapshots}
```

Game:
- reticle editor; HUD scale; speed indicator; damage numbers; weapon position; language.

Accessibility:
- colour-blind filters; reduce shake and flashes; UI scale.

Translations:
- every UI string is a key in a table; English file complete first, then French.
- A missing French key falls back to English; a missing key in both shows the key name.
- Haiku writes the French strings once the English keys are final.

## Public interfaces to create or respect
- `core`: `Bindings` (action to key or button, conflict check function), `Translations` loader (`t(key) -> &str`).
- `ui`: rebinding view with conflict result enum.

## Acceptance criteria
- `dev.ps1 test` passes:
  - rebinding an action to a bound key reports the conflict;
  - the French table has every key of the English table (100 % coverage test);
  - switching language changes every screen string on the next frame (test on the translation loader);
  - a missing key falls back as specified;
  - each audio and network setting applies without restart (apply function result).
- `dev.ps1 ci` passes.

## Out of scope
- Music; languages beyond English and French; gameplay changes.
