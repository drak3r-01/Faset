# Lot 5.6 — Catalogue of twelve original maps
- Model/effort: Opus, medium | Depends on: 5.5, 2.14 | Milestone: J5 (this lot closes phase 5)

## Goal
Twelve original maps are in `assets/maps/`, each valid, each trialled by bots, each human-checked before entry.

## Crates
- Owned: `assets/maps/*.ron` (content only) and map entries of the catalogue index if one exists.
- Read-only: `mapfmt`, `tools/map-tool`, `assets` (prop recipes, about 150 from lot 2.14), `sim`, `bots`.
- Forbidden: any code change; if the map tools fail, stop and report.

## Spec
Work in sessions of two maps each (6 sessions). Use the authoring loop and the dimensions in `docs/map-design-guide.md` (lot 5.5). Each map must apply the principle below, and must not copy the layout or name of any existing game map.

| Map | Setting and mood | Design principle |
|---|---|---|
| Souk | desert city, day | three corridors and chokepoints |
| Cargo | container dock, dusk | small map with constant action |
| Orbital | space station | low-gravity zones, corridors and airlocks |
| Abyss | underwater base | tight interiors, submerged exterior |
| Neon Rooftops | night rooftops, neon | verticality, jump pads |
| Timberline | sawmill in forest | elevated central point to hold |
| Mesa Fort | two forts in a canyon | symmetric bases linked by a bridge |
| Frostbite | snowy village, storm | long lines of sight |
| Metro | underground station | corridors, trains, flanking routes |
| Toybox | giant room | miniature players, shifted scale |
| Arena Zero | abstract arena | pure duel, jump pads, central pickups |
| Sunken Temple | jungle temple, rain | loop around a central courtyard |

Each map: file name = map id in lowercase kebab-case; symmetry declared where the principle needs it; theme and weather set.

## Public interfaces to create or respect
- Map files conform to `mapfmt` schema and version as currently defined. No new fields.

## Acceptance criteria
- `dev.ps1 maps validate` passes for all 12 maps.
- `map-tool trial` (lot 5.5) produces a report for each of the 12 maps, stored in the PR description summary.
- Each map passes the 3-round correction limit and has a human validation note in its PR commit.
- No map name or layout matches an existing commercial map (human check recorded).
- `dev.ps1 ci` passes.

## Out of scope
- New prop recipes (lot 2.14 is done); balance tuning of weapons; map vote.

## Session protocol
1. Read `CLAUDE.md` and this file.
2. Do not use graphify until the repo contains Rust code; then query it (`graphify query`, `path`, `explain`) before grepping.
3. Branch `lot/5.6-map-catalogue-twelve`. All commands run in Docker (`dev.ps1 <cmd>`), never on the host.
4. Run `dev.ps1 ci` (= `cargo xtask ci`) before merge; it is the only quality gate.
5. Conventional Commits in English; one lot = one branch = one PR; run `graphify update .` once code exists.
6. Short report: delivered, tests passed, deviations from this file.

Conventions: repo content in English (map names included); metres/seconds/radians; right-handed, Y up, -Z forward; data RON; never change a crate's public interface you do not own.
