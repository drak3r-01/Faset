# Lot 8.5 - Organic modelling primitives for prop recipes (phase 8, world)

Not in the reference plan. Phase 8 turns the arena maps into believable worlds (see `README.md`).

- **Model/effort:** Opus, high | **Depends on:** 2.13, 6.11 | **Branch:** `lot/8.5-organic-prop-primitives` (one PR)
- **Owns:** `assets` (recipe language and mesh generation), `asset-tool`. No new external assets.

## Goal

Prop recipes can describe real shapes (rounded, curved, bevelled), not only boxes and spheres.

## Spec

1. New recipe operations: **lathe** (revolve a profile: barrels, lamps, vases), **extrude along path** (pipes, fences, cables, rails), **bevel/round** edges, **subdivision smoothing**, **taper/bend/twist**, **vertex noise** (rock, bark, worn edges), **mirror/array/scatter** along a line or ring.
2. Per-vertex colour variation and wear (dirt at the base, rust, moss) driven by height and normal, in our own palette.
3. Triangle budget raised for hero props (up to about 800) and still 20 to 200 for small ones; per-prop LOD generated automatically (feeds 8.2).
4. Existing recipes keep working unchanged; the contact sheet tool shows before/after.

## Acceptance

`cargo xtask ci` green; unit tests for each operation (watertight, normals, budget); contact sheet of one example per operation reviewed visually; all existing recipes still validate.
