# Lot 2.3 — WGSL shader chain, hot reload, procedural materials
- Model/effort: Sonnet, moyen | Depends on: 2.2 | Milestone: none

## Goal
Build the `shaders` crate (WGSL sources compiled to SPIR-V at build time, optional hot reload) and procedural material patterns chosen by the vertex material id, so a swatch of all patterns matches its reference.

## Crates
- Owned: `shaders` (create if absent; no dependencies), and the material part of `render`.
- Read-only: `core`. `render` public interfaces from 2.1-2.2 must not break.
- Forbidden: all other crates.
- Build deps for `shaders`: `naga` (WGSL frontend and SPIR-V backend), used in `build.rs`.

## Spec (condensed)
- WGSL sources live in `shaders/src/*.wgsl`. A minimal include preprocessor: a line `#include "name.wgsl"` is replaced by that file, once per file (shared functions).
- `build.rs` compiles every entry point to SPIR-V with `naga`; output is embedded in the binary with `include_bytes!`. A shader error fails the build.
- Cargo feature `hot-reload` (dev only): watch the source directory, recompile changed files at runtime with naga, swap the pipeline on success. On error keep the previous pipeline and log with `tracing::error!`. No game restart.
- Materials are procedural, computed in the fragment shader in world coordinates with triplanar projection. Patterns are filtered with `fwidth` so they do not shimmer at distance.
- Pattern table (material id -> pattern):
  - `flat`, `gradient` (gradient by height): plain surfaces.
  - `noise`: slight hue variation (sand, rock, grass).
  - `checker`, `stripes`, `grid`: floors, markings, panels.
  - `brick`, `planks`, `tiles`: walls and floors.
  - `ripples`: dunes, snow.
  - `water`, `lava`: animated surfaces.
  - `emissive`, `hologram`: neon, screens, space decor.
- Material table is data in RON: id (u8), pattern, colour A, colour B, scale (metres), animation speed. Parse with `serde` + `ron`.

## Public interfaces to create or respect
- `shaders` exposes the embedded SPIR-V blobs by name, e.g. `shaders::OPAQUE_VS`, `shaders::OPAQUE_FS` (`&'static [u32]`).
- `render::MaterialTable` loaded from RON: `fn get(&self, id: u8) -> Option<&Material>`.
- Hot reload API (feature-gated): `render::ShaderWatcher::poll(&mut self, renderer: &mut Renderer)`.

## Acceptance criteria
- `cargo xtask render-test`: a test scene with one swatch per pattern matches `render/tests/refs/pattern_swatch.png` within tolerance 1 per channel.
- Build: a deliberately broken WGSL file makes `cargo xtask build` fail (check once, then revert).
- Hot-reload test (feature on): modify a copy of a shader in a temp dir, the new pipeline is active within 60 frames; a broken edit keeps the old pipeline and emits an error log.
- Unit: RON material table parses; missing id returns `None`.
- Zero validation-layer messages in `render-test`.
- Far-distance test: pattern contrast at 1 km is within 5 % of the mean (no aliasing shimmer), measured by a fixed camera.

## Out of scope
Lighting model (2.4), shadows, per-vertex ambient occlusion (3.2), texture files (none in this project), sky, weather, water surfaces with Gerstner displacement (2.8).
