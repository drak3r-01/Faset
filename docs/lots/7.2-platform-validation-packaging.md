# Lot 7.2 — Platform validation and packaging
- Model/effort: Sonnet, medium | Depends on: phase 6 complete (no explicit list in the plan) | Milestone: none

## Goal
Each build target compiles, one archive with checksums is produced per target, and the Windows client runs on the host GPU.

## Crates
- Owned: `xtask` (`package` command, target handling).
- Read-only: everything else. The release workflow `.github/workflows/release.yml` must match section 3; change it only if it deviates.
- Forbidden: changing public interfaces of any crate.

## Spec
Targets (section 3):
| Target | Method | Where |
|---|---|---|
| `x86_64-pc-windows-msvc` | `cargo-xwin` | Docker |
| `aarch64-pc-windows-msvc` | `cargo-xwin` | Docker |
| `x86_64-unknown-linux-gnu` | native | Docker |
| `aarch64-unknown-linux-gnu` | cross linker and sysroot | Docker |
| `aarch64-apple-darwin`, `x86_64-apple-darwin` | native, MoltenVK embedded | GitHub CI macOS machines (experimental) |

- `cargo-xwin` downloads the Microsoft Windows SDK; its licence must be accepted in the image configuration.
- DLSS (`dlss` option) is Windows x86_64 only; the NGX SDK is fetched during the Docker build and is not versioned in the repo. Its licence is read in lot 2.12.
- MoltenVK targets use Vulkan base 1.2.
- `xtask package`: one archive per target, plus a checksum file (SHA-256).
- The Windows client is copied into `dist/` and run on the host to use the real GPU. Nothing else is installed on the host.

## Public interfaces to create or respect
- `xtask package [--target <t>]`: produces `dist/<target>.<ext>` and `dist/SHA256SUMS`.

## Acceptance criteria
- `dev.ps1 build --target <t>` succeeds for the four Docker targets (macOS builds verified by CI only).
- `dev.ps1 package` yields one archive per target and a `SHA256SUMS` file; `sha256sum -c` passes.
- Host check: the Windows x86_64 client from `dist/` starts, reaches `MainMenu`, and loads the sample map; result recorded in the PR.
- `cargo tree` check still shows `dedicated` without `ash` and `winit`.
- `dev.ps1 ci` passes.

## Out of scope
- Release publication and tag (lot 7.3); signing or installers; macOS support beyond experimental.
