# Lot 2.4 — Stylised lighting, point lights, fog, ambience profiles
- Model/effort: Opus, moyen | Depends on: 2.3 | Milestone: none

## Goal
Implement the stylised lighting model, up to 32 point lights, height fog, and the `AmbienceProfile` data type with its nine RON profiles; one reference image per profile.

## Crates
- Owned: `render` (lighting, fog, profile types); WGSL changes in `shaders`.
- Read-only: `core`. Do not change `core`.
- Forbidden: all other crates. The `ambience` data files live under the repo's data folder (RON).

## Spec (condensed)
- Banded diffuse ramp per light i, between shadow colour C_ombre and light colour C_lumière, threshold t, softness s (plan form):
```
R = \mathrm{mix}\big(C_{ombre},\ C_{lumi\grave{e}re},\ \mathrm{smoothstep}(t - s,\ t + s,\ N \cdot L)\big)
```
- Hemispheric ambient between ground colour and sky colour (plan form):
```
A = \mathrm{mix}\big(C_{sol},\ C_{ciel},\ 0{,}5\,N_y + 0{,}5\big)
```
- Rim light (silhouette separation), strength k_r (profile `rim` colour), power p (profile `rim` power):
```
\mathrm{rim} = k_r\,\big(1 - \max(N \cdot V, 0)\big)^{p}
```
- Final colour before fog (plan form), E emissive, o_i the shadow term of light i:
```
C = \mathrm{albedo} \cdot \Big(A + \sum_i R_i\, o_i\Big) + \mathrm{rim} + E
```
  Decision: the plan's R_i·o_i form makes o_i a visibility factor (1 = unshadowed). This lot has no shadow map, so o_i = 1 until 2.5 supplies it.
- Point lights: one uniform array of up to 32 lights (position, colour, radius). Attenuation (1 − (d/r)²)² clamped at 0; shader rejects d >= r. The plan gives no attenuation law: decision, kept as written.
- Exponential height fog (plan form; ρ0 = profile `density`, k = profile `falloff`, h0 = height reference, d = distance, r_y = y component of the view ray):
```
F = 1 - \exp\!\left(-\rho_0\, e^{-k\,(y_{cam} - h_0)}\ \frac{1 - e^{-k\, d\, r_y}}{k\, r_y}\right)
```
  Mixed toward the fog colour. The plan's fog colour is the sky colour in the view direction (seamless horizon); in this lot a flat profile colour is used, replaced by the sky in 2.6.
- `AmbienceProfile` fields: sun (colour, intensity, direction source), ambient (ground, sky), ramp (t, s), rim (colour, power), fog (colour, density, falloff), sky (parameters for 2.6), weather (for 2.7), exposure, grading (for 2.9), water (for 2.8).
- Two profiles blend by linear interpolation of every parameter (colours in linear space), factor in [0,1]. Used for hour and weather transitions.
- Provided profiles (one RON file each, one reference image each):
  - `day`, `sunset`, `night`: classic cycle.
  - `desert`: hard light, sand tones (heat haze in 2.7).
  - `space`: black starry sky, very contrasted light, no fog.
  - `underwater`: dense fog, caustics (2.8).
  - `snow`, `storm`: diffuse light, active weather (2.7).
  - `neon`: saturated night, strong emissives, marked bloom.

## Public interfaces to create or respect
- `pub struct AmbienceProfile` (serde, RON); `pub fn AmbienceProfile::blend(a: &Self, b: &Self, t: f32) -> Self`.
- `pub struct PointLight { pub position: Vec3, pub color: Vec3, pub radius: f32 }`.
- `RenderWorld` gains `lights: Vec<PointLight>` (max 32, extra dropped with a warning) and `ambience: AmbienceProfile`.

## Acceptance criteria
- `cargo xtask render-test`: one reference image per profile (nine images, `render/tests/refs/profile_<name>.png`) matches within tolerance 1 per channel.
- Unit: `blend(a, b, 0) == a` and `blend(a, b, 1) == b` for every field; midpoint is the average.
- Unit: a point light at distance >= radius contributes exactly zero.
- Unit: lights list of 40 is truncated to 32 and logs one warning.
- Unit: all nine RON profiles parse and validate (ranges: density >= 0, t, s in [0,1]).
- Zero validation-layer messages.

## Out of scope
Shadow maps (2.5), sky rendering and sun direction from time (2.6), weather particles (2.7), water and caustics (2.8), grading and bloom (2.9), clustered lighting (only if profiling later demands it).
