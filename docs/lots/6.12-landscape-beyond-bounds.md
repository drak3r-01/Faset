# Lot 6.12 - Landscape beyond bounds (internal lot)

Not in the reference plan. Maps end at the edge of the playable area; the world should continue beyond it.

- **Model/effort:** Sonnet, high | **Depends on:** 6.10, 6.11 | **Branch:** `lot/6.12-landscape-beyond-bounds` (one PR)
- **Owns:** `client::look` and scenery rendering. **Additive changes allowed in:** `mapfmt` (scenery/border data), `assets`, `docs`.

## Goal

Each map sits in a believable, original landscape, with limits that feel natural.

## Spec

1. Terrain and scenery continue outside the playable area (far terrain, low detail, distance fade).
2. **Varied borders per map**, original: e.g. a villa map with forest on one side and a cliff down to a beach on the other; an island map surrounded by sea you cannot leave.
3. **Natural/invisible limits:** cliffs, dense forest, sea, steep slopes; the simulation keeps the hard boundary (kill or soft push-back) without a visible wall.
4. **Distance fog and sky per theme**, horizon silhouettes (mountains, treeline, sea line).
5. Scenery data lives in the map file (backward compatible) and is cheap to render (instanced/low LOD).

## Acceptance

`cargo xtask ci` green; lavapipe screenshots from spawn and from the border of each existing map without validation messages; test that the playable boundary still contains players.
