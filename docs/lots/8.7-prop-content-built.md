# Lot 8.7 - Prop library, built themes (phase 8, world)

Not in the reference plan. Phase 8 turns the arena maps into believable worlds (see `README.md`).

- **Model/effort:** Sonnet, medium | **Depends on:** 8.5 | **Branch:** `lot/8.7-prop-content-built` (one PR)
- **Owns:** Data only, `assets/props/<theme>/*.ron`. Same rules as 8.6.

## Goal

About 100 new or reworked props for urban, industrial, market, harbor and interior themes.

## Spec

1. Crates and pallets, containers, cars and vans, market stalls, awnings, street lamps, bins, pipes and tanks, cranes, shelves, sofas, tables, doors, windows, stairs, railings, signage.
2. Variants per prop, worn and clean versions, colour accents from the map palette.
3. Cars and large props get simple compound colliders.
4. Same session rhythm as 8.6.

## Acceptance

Same acceptance as 8.6 with at least 100 recipes.
